## Agentic opportunity

The gaps list is the surface. An agent could read the unanswered questions
and say which ones the documents already attached to this assessment
answer — "your architecture note describes the retention period; do you
want to answer the data question from it?" — with the sentence quoted and
the source named. It proposes; the person answers. That is §22.1's drafting
capability aimed at exactly the moment a person is about to submit with
holes in the record.

Guardrails: it may never fill a gap itself, and it may never touch the
declaration — a declaration is a person's statement about their own
knowledge, and an agent that pre-ticks it has forged a signature. Nothing
here forecloses it: gaps are derived, named, and already carry the question
text an agent would need.
