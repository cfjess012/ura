# UAT — S11

**Done when:** the three §6.1 seams exist in code, nothing agentic is reachable from the product, and the deployment path is written.

Every requirement this slice owns gets a row below. Fill each one with what
was actually done and actually observed — "works" is not evidence. A row
marked `fail` needs a follow-up note saying how it will be addressed.

### §6.1 — Agent access is one module and nothing else addresses the agent

- **What was done:** Built `src/lib/agent.ts` with three transports and asserted the rule mechanically rather than trusting it.
- **What was observed:** `grep -rn AGENT_URL src/` returns `agent.ts` and `config.ts` only — config being the one module allowed to read the environment at all. The default transport is `none`: it returns "No agent is connected, so nothing was drafted. Everything on these screens is worked out by rules, not by a model," marked non-retryable because it cannot succeed. `agentcore` throws by name, so switching to it before it exists fails at the seam instead of somewhere else.
- **Result:** pass
- **Evidence:** `test/unit/architecture.test.ts` — "only the agent seam knows how the agent is reached"; `test/unit/agent-seam.test.ts` — 8 tests; independent verification confirmed the grep.

### §6.1 — Session state is one module, shaped for an AgentCore Memory swap

- **What was done:** Built `src/lib/session.ts` deliberately narrower than the table behind it, and attacked the table directly.
- **What was observed:** The interface is `append` and `history` and nothing else — no query, no filter, no update — because a memory service offers those differently or not at all, and an interface shaped around today's SQL would have to be redesigned to move. Conversation turns are insert-only: `UPDATE` and `DELETE` are both refused by trigger, an unknown speaker is refused, an empty turn is refused.
- **Result:** pass
- **Evidence:** `test/integration/invariants.test.ts` — "conversation turns are insert-only"; `test/unit/architecture.test.ts` — "only the session seam reads conversation state".

### §6.1 — Model access: the web application never imports a model SDK

- **What was done:** Asserted it as a test rather than a convention.
- **What was observed:** `grep -rn "anthropic|bedrock-sdk" src/` returns zero hits. Only `agent/src/model.ts` constructs a client. `AGENT_PROVIDER` switches between the Anthropic API and Bedrock with no other code path differing — verified by running the whole drafting flow against a local Ollama over the identical Messages API.
- **Result:** pass
- **Evidence:** `test/unit/architecture.test.ts` — "the web application never imports a model SDK"; independent verification repeated the grep.

### §7 — Nothing unbuilt is reachable from the product

- **What was done:** Ran the product with no agent connected, which is how the E2E suite runs.
- **What was observed:** No assistant, no launcher, no placeholder — the component is not on the page. The report renders complete without its summary and without a shimmer that never resolves. The intake assistant passes rather than blocking.
- **Result:** pass
- **Evidence:** `e2e/ai-surfaces.spec.ts` — 5 tests, all on the no-agent path; `e2e/policy.spec.ts` — "with no agent connected the assistant is absent, not apologetic".

### §6.4 — The deployment path is written and the container is correct

- **What was done:** Built and ran the production artifact; read the container against what a first deploy actually does.
- **What was observed:** Four defects, each of which would have failed the first attempt and looked like something else — no `.dockerignore` (`.env` would have shipped inside the image), `HOSTNAME` unset (binds to localhost, reads as a crash loop), no `packageManager` (corepack picks a mismatched pnpm), and no health endpoint avoiding the database. `/healthz` returns 200 and `/readyz` 503-with-reason against a deliberately dead database, where `/` returns 500.
- **Result:** pass
- **Evidence:** Measured against an unreachable database; `deploy/READINESS.md`; G-62.

## Findings

**The plan of record named a service the account cannot create.** App Runner
closed to new customers on 30 April 2026 — the owner caught it. Compute is
ECS Express Mode now (G-62), and the correction generalises: a deployment
target named in a specification is a claim about the world, and the world
moves.

**The seams were built before any model call, exactly as §6.4 required**,
and that turned out to matter: every capability in S12 plugged in behind
them without changing anything above.

## Agentic opportunity

This slice _is_ the opportunity's foundation, so the registration is the
inverse: what the seams must never become. AgentCore is substrate and never
the decider (§7); the session seam stays narrow so Memory can replace it;
and the model seam exists so that no other module ever learns a model is
there. A capability that needs to widen a seam is a capability that should
be questioned first.
