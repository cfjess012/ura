## Findings

**One defect found by walking, not by testing.** The Yes option's sub-label
read *"We'll ask more about this area later"* on all eleven areas — false for
the seven that ask nothing, and a promise the product cannot keep. It is the
same defect this slice exists to remove, one layer down: a label is a claim.
Fixed by conditioning the copy ("We'll record it for a reviewer") and pinned
by a test. The tests written before the walk all passed while that sentence
was on screen — which is the argument for the walk.

## Agentic opportunity

An agent could tell a requester what a quiet area's Yes actually triggers
downstream — which reviewer group picks it up, what they typically ask for —
so "recorded for a reviewer" names a person and a next step rather than a
destination. Guardrails: it reads the routing already computed and the
reviewer groups already seeded; it never invents a service-level promise or
a date. Human decision it must never take: whether the area applies.
